# paws-escape


 Built With
Unity
C#
2D Pixel Art
PC & Android support

A cozy 2D pixel-art puzzle-platformer where you play as a curious cat trying to escape from the house.
Explore cozy environments, solve small puzzles, collect keys, and find your way through each level. The game focuses on a relaxing atmosphere, comfortable UI, and simple puzzle-solving.

 Features
 Small environmental puzzles
 Jigsaw-style puzzles
 Collect keys to unlock new levels
 2 levels + lobby
 Automatic saving
 Cozy 2D pixel-art style
 Relaxing atmosphere
 PC and Android support
 Player Pointer Mechanic

One of the game's main mechanics is that the player's pointer exists physically in the game world.

Android: the player's finger acts as the pointer

The cat can use the pointer as a platform to jump on, creating an unusual interaction between the player and the game world.

Controls
Interact - Action
Arrows -	Move
Jump Button -	Jump
Bag Icon	- Open / close inventory
Collar Icon -	Open / close pause menu

The game contains:
Lobby — the main area connecting the levels
Level 1 — solve puzzles and find keys
Level 2 — continue your escape and solve new puzzles
New levels are unlocked by collecting the required keys.

Automatic saving is available, so your progress can be preserved without manually creating save files.
